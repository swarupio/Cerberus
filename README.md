# Cerberus

Chaos engineering and observability platform. Phase 0 contains structure-only
placeholders; the application is not runnable yet.

The Compose stub lists gateway, user-service, order-service, Prometheus, and
Grafana. The chaos-tool folder is reserved for a manual Node.js CLI outside
Compose. The observability folder is reserved for Prometheus and Grafana config.

See PRD.md for scope and WORKFLOW.md for the task checklist.
